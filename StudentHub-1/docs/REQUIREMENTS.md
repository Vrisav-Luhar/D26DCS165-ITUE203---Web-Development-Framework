# StudentHub Requirements

## Functional requirements
- FR-01: Provide a home page describing StudentHub.
- FR-02: Provide About, Events, FAQ, Contact, and Feedback pages.
- FR-03: Provide Login and Register entry points.
- FR-04: Plan separate dashboard experiences for Student, Faculty, and Admin.
- FR-05: Plan student and event administration for authorized administrators.
- FR-06: Support later integration with PHP and MySQL.

## Non-functional requirements
- NFR-01: Use semantic HTML.
- NFR-02: Keep navigation consistent across pages.
- NFR-03: Keep the layout readable at different viewport widths.
- NFR-04: Use clear labels and feedback for form controls.
- NFR-05: Validate user input on the server when backend processing is added.
- NFR-06: Restrict protected functions using server-side authorization.
- NFR-07: Keep source files organized and maintainable.

## Assumptions and limits
This is the initial planning document. Requirements may be refined as the practical series progresses. It does not claim that all planned functions are implemented in Practical 1.
