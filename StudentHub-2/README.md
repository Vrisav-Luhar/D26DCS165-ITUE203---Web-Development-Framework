# StudentHub — Practical 2
## Semantic HTML5 Pages with Accessibility-Ready Structure

**Aim:** Develop static HTML5 skeletons for at least 10 StudentHub pages using semantic HTML and accessibility-friendly structure.

### Included
Static HTML pages for Home, About, Register, Login, Dashboard, Events, Profile, Contact, Admin, FAQ, and Feedback. The pages are based on the StudentHub files provided for consistency.

### Practical 2 scope
This practical focuses on semantic HTML5 and accessibility-ready structure. CSS styling and JavaScript files are intentionally not included. CSS layout and responsiveness belong to Practical 3; JavaScript DOM manipulation and interactivity belong to Practical 4.

### How to run
Open `index.html` in a browser, or use VS Code Live Server. Test the navigation links between pages.

### Submission checklist
- [ ] At least 10 HTML pages included.
- [ ] Navigation links connect pages correctly.
- [ ] Semantic HTML elements are used appropriately.
- [ ] Form fields have associated labels.
- [ ] Heading hierarchy is logical.
- [ ] Images, if present, have appropriate `alt` text.
- [ ] Keyboard navigation is checked.
- [ ] Capture screenshots of static pages for submission.
