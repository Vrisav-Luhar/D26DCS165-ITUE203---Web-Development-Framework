# Practical Mapping — StudentHub

This mapping follows the titles in the ITUE203 WDF Practical List supplied for this project. The exact files in a consolidated folder may include legacy or demonstration pages; confirm each item in the final project before submission.

| Practical | Title / concept | Evidence to include |
|---:|---|---|
| 1 | Project initiation, requirements, sitemap, wireframe, GitHub | Requirement notes, sitemap/wireframe, repository |
| 2 | Semantic HTML5 pages and accessibility-ready structure | HTML pages and screenshots |
| 3 | Responsive CSS layout using Grid/Flexbox | CSS file and desktop/mobile screenshots |
| 4 | JavaScript DOM manipulation and interactivity | `js/script.js`, interaction screenshots |
| 5 | Registration form frontend validation | Valid/invalid form test evidence |
| 6 | Fetch external JSON, search/filter/sort/pagination | `data/*.json`, rendered UI screenshots |
| 7 | PHP form processing and CSV/JSON storage | `contact.php`, `feedback.php`, `process/`, CSV files |
| 8 | MySQL schema, ER model and PDO connectivity | SQL schema, ER diagram, database test |
| 9 | Secure registration, duplicate email check, password hashing | `register.php`, database evidence (no plaintext passwords) |
| 10 | Login/logout, sessions, roles, timeout, remember-me | `login.php`, `logout.php`, auth helpers and migration |
| 11 | Student management CRUD | `admin/students.php` and related handlers |
| 12 | Event management CRUD and upload validation | `admin/events.php` and event handlers; document upload behavior actually present |
| 13 | PHP JSON API and Fetch CRUD | `api/`, `api-demo.php` |
| 14 | Admin dashboard and dynamic menu | `dashboard.php`, `includes/dynamic_menu.php` |
| 15 | Integration, testing, documentation, GitHub and local deployment | README, report, checklist, SQL export, screenshots, GitHub URL |

## Evidence naming suggestion

Use descriptive filenames such as:
- `screenshots/01-home-page.png`
- `screenshots/02-registration-validation.png`
- `screenshots/03-admin-dashboard.png`
- `screenshots/04-student-management.png`
- `screenshots/05-event-management.png`
- `screenshots/06-fetch-api-crud.png`
- `screenshots/07-student-dashboard.png`
- `screenshots/08-database-tables.png`

Do not include passwords, cookies, or unnecessary personal information in screenshots.
